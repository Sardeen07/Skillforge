Implement verify_webhook in webhooks.py so we only process genuine events from our payment provider. Their docs: every request carries a header `Provider-Signature: t=<unix timestamp>,v1=<signature>`, where the signature is the hex HMAC-SHA256 of `<timestamp>.<raw request body>` keyed with our signing secret. Return the parsed JSON event, and raise InvalidSignature for requests that should not be processed.
